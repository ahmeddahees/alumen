# 🪟 حاسبة ورشة الألوميتال | الإصدار الهندسي المطور

برنامج متكامل لحساب مطابخ الألوميتال وفق القواعد الفنية الدقيقة للورش:

---

## 🌟 القواعد الفنية المعتمدة في هذا الإصدار:

### 1. 📏 تعديل معادلة ارتفاع الفاصل:
$$\text{ارتفاع الفاصل} = \text{الارتفاع الكلي} - (\text{خصم التجميع} \times 2)$$
*(مثال المعلم: ارتفاع الوحدة 80 سم مع خصم 2.5 سم $\implies 80 - (2.5 \times 2) = \mathbf{75\text{ سم}}$).*

---

### 2. ⚡ خيار تقسيم (الثلث والثلثين - درفة ودرفتين بفاصل 1):
- زر جديد مخصص في التقسيم الذكي: **`[ثلث وثلثين (درفة ودرفتين)]`**.
- يقوم البرنامج تلقائياً بالتالي:
  1. خصم الفريم الخارجي والفاصل: $\text{صافي العرض} = \text{العرض} - (3 \times \text{خصم التجميع})$.
  2. **قسم التلت (1/3):**
     - رف بعرض: $\frac{\text{صافي العرض}}{3}$
     - درفة واحدة مفردة بعرض: $\text{عرض رف التلت} + 2.3\text{ سم}$.
  3. **قسم التلتين (2/3):**
     - رف بعرض: $\frac{2 \times \text{صافي العرض}}{3}$
     - درفتين مزدوجتين، كل درفة بعرض: $\frac{\text{عرض رف التلتين} + 2.3}{2}$.

---

### 3. 📐 عمق الرف ثابت:
- يطابق دائماً وتلقائياً **عمق الوحدة** التي أدخلتها.

---

### 4. 🚪 معادلة مقاس الدرفة وشرط الـ 45 سم:
- **المعادلة الأساسية:** $\text{عرض الدرفة} = \text{عرض الرف} + 2.3\text{ سم}$.
- **شرط الـ 45 سم:** إذا كان عرض الدرفة الناتج $> 45\text{ سم}$، يتم تقسيمها أوتوماتيكياً لدرفتين بعرض $(\text{عرض الرف} + 2.3) / 2$.
- **ارتفاع الدرفة:**
  - **مقبض خارجي:** $\text{ارتفاع الفاصل} + 3.0\text{ سم}$ (مثال: $75 + 3 = 78$ سم).
  - **بلت إن:** $\text{ارتفاع الفاصل}$ (75 سم بدون زيادة).
